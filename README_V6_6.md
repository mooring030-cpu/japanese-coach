# ANTHONY 日本語 COACH v6.6

- 위치 표현: 前 / 隣 / 手前 / そば 시각 구분 강화
- 모든 학습 결과: 다시 / 이해 / 완벽 3단계 버튼 공통화
- 버튼 길게 누르기: 카드별 복습일 직접 설정
- 연속 정답 시 이해/완벽 복습 주기 자동 증가
- 동사 활용 문제에 활용된 한국어 의미를 문제/정답 화면에 명확히 표시
- 자주 헷갈리는 유사 표현에 상황별 차이 설명 추가
- 날짜·숫자·조수사: 다중 선택 드롭다운으로 시험 범위 지정
- 자동로그인: 새로고침/일시적 네트워크 오류에서 세션을 삭제하지 않도록 보강, 세션 이중 저장, 아이디 기억
- 모바일 UI 및 하단 복습 버튼 사용성 개선
