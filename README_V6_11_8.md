# YOMIAN JAPANESE v6.11.8

- N4 별도 단어를 68개 전체학습 방식으로 변경: 한 번 시작하면 68개를 모두 최소 1회 풀이
- 출제 방식 선택: 2단계 모두 / 뜻→한자 / 히라가나→한자 / 한자→히라가나 / 혼합
- 정답 후 한자·일본어 표기 + 히라가나/가타카나 읽기 + 한국어 뜻을 함께 표시
- 2단계 완전학습에서는 1단계에서 읽기를 숨겨 2단계 정답이 노출되지 않도록 유지
- 맞힌 단어도 `오늘 다시`를 눌러 추가 복습 가능
- `내일 복습` 버튼 추가: 오늘 추가 반복 없이 다음 날 복습 예약
- `직접 설정`으로 원하는 복습일 지정
- 오늘 다시로 선택한 문제는 68개 1회 풀이를 마친 뒤 복습 큐에서 재출제
- 68개를 모두 한 번씩 풀면 `오늘 학습 완료` 처리
- 기존 N4/N5~N1, Supabase 로그인/동기화 및 기존 학습기록 유지
