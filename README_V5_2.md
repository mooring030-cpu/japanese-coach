# DACO 일본어 코치 v5.2

추가 기능
- 문법·활용 사전: 동사 316개 활용표, 자주 쓰는 문장 패턴, 문법 99개
- 동사 변형 맞추기 10문제: ます/て/た/ない/가능/의지/ば/수동/사역
- 자주 쓰는 문장 완성 10문제: 〜と思います, 〜ようと思います, 〜たいです, 〜てください, 〜てもいいですか, 〜なければなりません 등
- 오답 즉시 재도전 + 세션 뒤쪽 자동 재복습
- 훈련 진행상태와 누적 정확도는 기존 사용자 state에 포함되어 Supabase 클라우드 동기화
