# ANTHONY 日本語 COACH v6.5

## 추가 기능
- 접속사 전용 탭/퀴즈: 이미지의 そして・それで・だから・しかし・けれども・それでも・それでは・では・ところで 포함, 총 40개
- 업로드 단어 모음 반영: N5 480, N4 573, N3 511, N2 1168, N1 1000
- N5~N3 누락 단어를 기존 10분 학습 DB에 중복 없이 보강
- N2/N1 별도 단어 학습 탭 및 10문제 퀴즈
- 일본어 성우 선택: 기기 내 일본어 음성 중 자연스러운 후보 최대 3개 + 자동
- 선택한 성우/복습 기록은 사용자 상태에 저장
