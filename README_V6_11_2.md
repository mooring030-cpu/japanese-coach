# YOMIAN JAPANESE v6.11.2

## Branding
- App name: `YOMIAN JAPANESE`
- Short installed name: `YOMIAN JP`
- Brand family: `YOMIAN`
- New study-themed icon applied to standard and maskable PWA icons.

## Compatibility
- Existing account/session storage keys and learning IDs are intentionally preserved so current users keep their login and study progress.
- The PWA scope/start URL remain unchanged, allowing the existing installation to receive the new branding through normal manifest/service-worker updates where the OS supports it.
- Some iOS home-screen installations may keep the old launcher name/icon until the app is removed and added to the Home Screen again.
