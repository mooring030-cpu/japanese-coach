# YOMIAN JAPANESE v6.11.3

## 설치 이름/아이콘 갱신 보강
- manifest 파일 경로와 start_url/scope는 기존과 동일하게 유지
- YOMIAN 아이콘 URL을 새 버전 파일명으로 변경하여 Android Chrome WebAPK 메타데이터 변경을 명확히 감지
- manifest shortcuts 추가로 메타데이터 변경 트리거 보강
- 설정 > 앱 이름·아이콘 갱신 메뉴 추가
- Android에서 about://webapks 강제 업데이트 안내 추가
- 기존 학습/로그인/클라우드 저장 키는 변경하지 않음

주의: Chrome 인터넷 사용기록 삭제는 설치된 WebAPK를 삭제하지 않습니다. 기존 설치 앱의 이름/아이콘 갱신은 Android/Chrome이 별도 처리하며 즉시 강제할 수 없습니다.
